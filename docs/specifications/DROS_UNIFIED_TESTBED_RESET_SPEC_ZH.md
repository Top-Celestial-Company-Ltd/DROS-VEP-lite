## 🔄 二、 確定性測試生命週期 (Deterministic Test Lifecycle)

為了保證測試的高可靠性與一鍵自愈復原，每一個測試軌道強制實施四大生命週期階段：

1. **`SetUp(Scenario_Config)`**：
   * 載入該場景專屬的 `policy.json`（如無人機關注 `DISARM`，手機關注 `RESTRICTED_ACCESS_PHOTOS`）。
   * 記錄初始狀態指紋 $S_{\text{init}} = \text{SHA256}(\text{Memory\_State})$。
2. **`Execute(Adversarial_Payloads)`**：
   * 注入數千次提示詞攻擊、越權呼叫與競態干擾。
   * 核心門閘實施 $< 500\text{ns}$ 二進位攔截。
3. **`Assert(Invariants)`**：
   * 驗證物理狀態抑制率 $\Delta I_{\text{physical}} = 1.0$（未授權執行次數 $\equiv 0$）。
4. **`TearDown_And_Reset()`**：
   * 調用核心重置協議，強制釋放所有動態配置與快取，確保 $S_{\text{final}} \equiv S_{\text{init}}$。

## 🚀 三、 全自動總控評測器 (Master Benchmark Runner)

使用者或審計員僅需在專案根目錄執行單一指令：

```bash
python run_all_benchmarks.py
```

系統將依序自動完成：
* **[Track 1--4]** B2B 雲端網關與紅隊對抗套件（Suites A--F） ➔ **自動 Clean Reset**
* **[Track 5]** 實體無人機空中 Disarm 熔斷與 100 機蜂群 Mesh 防禦 ➔ **自動 Clean Reset**
* **[Track 6]** 智慧手機 iOS Swift / Android Kotlin 端側防禦 ➔ **自動 Clean Reset**
* **[Summary]** 匯出全域統一安全評測成績單（Master Scorecard）
