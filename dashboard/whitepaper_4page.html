Executive Summary

傳統防禦體系（WAF、EDR、IAM）設計於固定功能軟體的威脅模型，根本性地無法覆蓋 AI Agent 執行邊界所衍生的攻擊面。當被挾持的 Agent 本身即為持有合法憑證的行動者，前三層防禦對其完全透明。DROS 四層縱深架構提供唯一的確定性出口：於 C-ABI 二進位邊界執行 O(1) 常數時間 Bitmap 策略查表——不讀字串、不做語意推論、物理熔斷。

Agentic Attack Vectors (AAV-2026) · 威脅模型定義
攻擊類型 MITRE ATLAS 技術描述
間接提示詞注入 (IPI) AML.T0051 攻擊者將惡意指令隱匿於 Agent 處理的外部資料（Invoice、API 回應），誘導執行攻擊者意圖的工具呼叫
目標劫持 (Goal Hijacking) AML.T0054 通過累積式語境污染（Context Poisoning）改寫 Agent 終極任務目標，誘導長鏈惡意動作序列
特權函式升級 (Escalation) AML.T0053 遭劫持 Agent 利用合法持有的 OAuth Token，超出角色範疇呼叫高權限函式（deploy_production）

核心不對稱：傳統模型假設攻擊者不持有合法憑證。Agentic Web 的根本性風險在於：被挾持的 Agent 本身即為持有合法 JWT Token 與 API Key 的行動者。L1-L3 全層對其無效。

為何傳統防禦在此失效 · Attack Path Model
傳統威脅模型（攻擊者無憑證）： [惡意外部輸入] ──► WAF 攔截 ──► 安全 Agentic Web 新威脅模型（持證遭劫 Agent）： [正常 Invoice PDF] ──► L1 WAF ❌透明 ──► Agent 讀取 [PDF 含隱藏 IPI 指令] ──► Agent 被劫持 ├── 持有合法 JWT ──► L2 ZTM ❌透明 ├── 持有合法 Token ──► L3 編排層 ❌透明 └── 嘗試 update_payment_account() ──► L4 DROS Bitmap[0] ✅ <500ns BLOCK 結論：L4 是唯一能在「持有合法憑證」前提下仍提供確定性阻斷的防線。

L4 三大核心設計原則
🔢
原則一：二進位 Bitmap 查表，根除語意模糊面
所有工具權限於編譯期被編碼為不可變數值點陣圖。決策為確定性布林運算：Bitmap[role][tool] = 1 → ALLOW，= 0 → DENY & PANIC。不存在概率空間，攻擊者無從利用語意等效替換繞過。
⚡
原則二：O(1) 常數時間執行，規模不退化
無論企業部署 10 條或 10,000 條安全策略，DROS 保證恆定決策延遲。不同於 ML 分類器在高負載下的線性效能退化，Bitmap 查表在規模上是數學恆定的。
🔒
原則三：C-ABI 子應用層執行，物理強制
DROS 部署於 C-ABI 邊界——應用層之下、Kernel 之上。惡意呼叫如 execute_sql("DROP TABLE...") 在到達資料庫引擎前即被物理阻斷，<500ns 執行緒強制終止，生成密碼學簽章稽核事件。
